# Security

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature when it is enabled
for the Cordspan repository. If private reporting is unavailable, contact the
repository owner privately instead of opening a public issue.

Do not include credentials, private hostnames, IP addresses, USB serial numbers,
or other sensitive machine information in a public report.

## Network scope

Cordspan manages USB/IP connections and is intended for trusted networks. Do
not expose USB/IP port 3240 directly to the public internet. Use an appropriately
secured private network or tunnel for access outside a trusted LAN.
