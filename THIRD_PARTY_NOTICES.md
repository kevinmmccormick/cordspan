# Third-Party Notices

Cordspan is built with third-party components obtained through NuGet, including
Microsoft Windows App SDK and MSTest. Those components are provided under their
own licenses. Refer to the resolved NuGet packages and their accompanying
license files for the versions used by a particular build.

Cordspan interoperates with separately installed command-line tools:

- `usbipd-win` provides USB/IP host operations on Windows.
- `usbip-win2` provides USB/IP client operations on Windows.

These tools are not included with Cordspan. Their names and project identities
belong to their respective maintainers, and users must install them separately
under the terms supplied by those projects.
